# 🏺 OSSIL Envases — Rediseño E-Commerce B2B/B2C Industrial

Plataforma moderna de comercio electrónico mayorista y minorista para **OSSIL Envases** (Oncativo 69, Local 1 — Córdoba Capital, Argentina). Especializada en envases de perfumería, cosmética, farmacéutica/medicinal, alimentos y accesorios (válvulas, bombas y tapas).

---

## 🛠️ Stack Tecnológico y Servidor

| Capa                       | Tecnología                                                                                     | Propósito                                                                                                                     |
| :------------------------- | :--------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| **Lenguajes**              | **TypeScript 5.9+** (Strict), **SQL** (PostgreSQL), **CSS** (Tailwind v4), **GLSL** (Three.js) | Tipado estático completo, consultas relacionales y shaders PBR de materiales.                                                 |
| **Framework Full-Stack**   | **Next.js 16 (App Router)** + **React 19**                                                     | Server Components por defecto, Partial Prefetching, Cache Components y Server Actions.                                        |
| **UI & Sistema de Diseño** | **Tailwind CSS v4** + **shadcn/ui** + **Lucide Icons** + **Motion**                            | Estética _Industrial Apothecary_ (Anti-Slop Visual) con cumplimiento estricto WCAG 2.2 AA/AAA.                                |
| **Estado & Filtros**       | **URL Search Params** + **Zustand** + **Zod**                                                  | Filtros facetados sincronizados en URL y carrito con cálculo de escalas mayoristas en vivo.                                   |
| **Visualización 3D**       | **Three.js** + **React Three Fiber (`@react-three/fiber`, `@react-three/drei`)**               | Visor 3D interactivo de envases con cambio de acabado en tiempo real (Cristal, Satinado, Ámbar, PEAD).                        |
| **Base de Datos & ORM**    | **PostgreSQL 16 (Supabase)** + **Prisma ORM**                                                  | Modelado relacional de catálogo, escalas por volumen (`PriceTier`) y compatibilidad de roscas (`18/415`, `24/410`, `28/400`). |
| **Servidor & Hosting**     | **Vercel (Edge Network)** + **Supabase Cloud**                                                 | Despliegue continuo CI/CD, CDN de baja latencia en Sudamérica y almacenamiento optimizado.                                    |
| **Calidad & Testing**      | **Playwright (E2E)** + **React Doctor** + **Schema.org JSON-LD**                               | Pruebas automatizadas de flujo de compra, auditoría de re-renders y SEO técnico/local en Córdoba.                             |
